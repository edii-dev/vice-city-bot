# Vice City Bot: Privacy Policy

**Effective date:** 18 November 2026

This policy explains what the Vice City Discord bot ("the bot", "we") stores, why, and how you can have it removed. Vice City is a fan-made game. It is not affiliated with Rockstar Games or Discord.

## What the bot stores

The bot stores only what it needs to run the game. It is stored per Discord server, so your progress in one server is separate from your progress in another.

- **Discord IDs:** your user ID and the ID of the server you play in.
- **Your server display name:** saved so leaderboards and crew lists can show your name. It is updated when you use the bot.
- **Game data:** in-game cash and bank balances, XP and skills, wanted level, cooldowns, vehicles, properties, businesses, items, crew membership and rank, heist and turf records, and a log of in-game money transactions.
- **Crew data:** crew names and tags that players choose.

## What the bot does not collect

- It does **not** read your messages. It only uses the `Guilds` gateway intent and responds to slash commands and button presses.
- It does **not** use privileged intents (Message Content, Server Members, Presence).
- It does **not** store your email, IP address, avatar, or any real-world payment information. There are no real-money purchases.
- Your avatar is loaded from Discord when a panel is shown. It is not saved.

## How the data is used

The data is used only to run the game: showing your profile, keeping balances correct, enforcing cooldowns, and running multiplayer features such as crews, heists, turf and mugging. Data is never sold, shared with third parties, or used for advertising.

Other players in the same server can see game information about you that the game displays, such as your level, crew, and profile.

## Logs

The bot keeps technical logs that can include user and server IDs and the name of the command used. These are used only to fix bugs and stop abuse, and are not shared.

## Storage and security

Data is stored in a PostgreSQL database controlled by the bot's operator. Access is limited to the operator.

## Keeping and deleting data

Game data is kept while the bot is in use, so your progress is not lost. To have your data deleted, open an issue on this repository with your Discord user ID (and the server ID, if you only want one server's data removed). All game data linked to that ID will be deleted. You do not need to give a reason.

## Children

You must meet Discord's minimum age requirement to use Discord, and therefore this bot.

## Changes

If this policy changes, the new version will be posted here with a new effective date.

## Contact

Questions or data requests: open an issue on this repository.
